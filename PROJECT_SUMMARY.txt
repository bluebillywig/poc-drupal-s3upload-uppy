HOW TO USE
--------------------------------------------------------------------------------

1. Configure AWS credentials:
   $ cp .env.example .env
   $ nano .env  # Add your AWS credentials

2. Run installation:
   $ ./install.sh

3. Install Drupal:
   Visit http://localhost:8080
   Database: drupal / drupal / drupal @ mysql

4. Enable module:
   $ docker-compose exec drupal drush en s3_uppy -y
   $ docker-compose exec drupal drush cr

5. Set permissions:
   Visit /admin/people/permissions
   Enable "Upload videos to S3"

6. Upload videos:
   Visit http://localhost:8080/s3-video-upload
